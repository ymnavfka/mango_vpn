# mango_vpn

Личный VPN с собственным приложением и автоматическим выбором маршрута: российские сайты открываются напрямую, остальные — через зарубежный сервер.

Проект начинается с Android. В дальнейшем планируется поддержка iOS, macOS, Linux и Android TV. Помимо повседневного использования, цель проекта — разобраться в устройстве VPN, DNS и маршрутизации.

Сейчас проект находится на этапе планирования: код не написан, сервер не выбран, технический стек окончательно не утверждён.
